SHADOW PAWS – Game Description

*Shadow Paws* is a 2D arcade survival game featuring a mysterious black cat exploring a dark and spooky graveyard. The player's mission is to collect as many fish bones as possible while avoiding dangerous ghosts wearing red robes.

Players must move carefully, avoid enemy attacks, and survive as long as possible to achieve the highest score. Every fish bone collected increases the score, but the game becomes more challenging as more ghosts appear.

The player has three lives. If all lives are lost, the game is over. Players can then try again and beat their previous high score.

*Game Features:*
- 2D arcade survival gameplay.
- A cute black cat as the main character.
- Fish bones to collect for points.
- Ghost enemies that move around the graveyard.
- Three lives to survive.
- Increasing difficulty as the score grows.
- High-score tracking.

*Objective:* Collect as many fish bones as possible, avoid the ghosts, and survive for as long as you can!
